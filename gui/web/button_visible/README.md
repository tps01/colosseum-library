# Button visible (web)

## Plugins

- `colosseum-gui` (`col.gui.web`)

## FILL_IN_HERE

| Name | Meaning |
|------|---------|
| `web_id` | `[[gui.web]]` id |
| `button_role` / `button_name` | Accessible locator for the control to click |
| `status_role` / `status_name` | Accessible locator that must become visible |

## Drivers

`sim` or `playwright`. Not desktop.
